# java-calculator-precourse

# 문자열 덧셈 계산기

## 🚀 기능 목록
- [ ] 사용자 입력 받기 (`Console.readLine()`)
- [ ] 빈 문자열 또는 공백 입력 시 0 반환
- [ ] 기본 구분자(쉼표, 콜론) 기준으로 숫자 분리
- [ ] 커스텀 구분자(`//`와 `\n` 사이) 파싱 및 분리
- [ ] 분리된 문자열을 양수로 변환하고 합산
- [ ] 예외 처리: 잘못된 입력이나 음수일 경우 `IllegalArgumentException` 발생
- [ ] 결과 형식에 맞춰 출력 (`결과 : {합계}`)
